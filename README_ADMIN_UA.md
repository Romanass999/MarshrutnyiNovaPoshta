# Адмін-панель «Маршрутний Нова Пошта»

## Що додано
- Дашборд статистики.
- Користувачі: створення, блокування/активація, зміна ролі, пароля та імені, видалення.
- Ролі: `courier`, `experienced`, `admin`.
- Маршрути: перегляд, пошук, редагування, створення, видалення, зміна статусу.
- Модерація маршрутів, запропонованих кур'єрами.
- Райони: створення, редагування, вимкнення, видалення.
- Оцінки маршрутів: перегляд і модерація.
- Журнал дій адміністратора.
- JSON-резервна копія даних.
- Перевірка стану API та PostgreSQL.
- Автоматичне створення таблиць при запуску.

## Адмінка
Після деплою відкрийте:
`https://ВАШ-RENDER-ДОМЕН/admin`

Після входу використовується JWT у браузері. Дані API захищені роллю `admin`.

## Render Environment
Потрібні:
- DATABASE_URL
- JWT_SECRET
- ADMIN_EMAIL
- ADMIN_PASSWORD
- ADMIN_NAME (наприклад `Адміністратор`)

Не публікуйте DATABASE_URL, пароль БД або JWT_SECRET.
